# Spec: 连接场景预设与自定义

## 状态

已批准并实现，日期：2026-08-01。审查发现的模态框焦点约束与保存状态测试缺口已通过后续 `@uxu-code:debug` 修复。

用户决策：

- 批准四个预设的名称、数值和“不单列视频加速”的产品判断；
- 只制作预设与自定义；
- 不制作自适应策略，不按应用或域名识别用途；
- “使用场景”下方的常驻长说明改为与 UUID 相同视觉和交互模式的 `!` 说明入口；
- 四项底层连接控件只在用户选择“自定义”时显示；
- 已完成的 XHTTP 规格归档到 `specs/xhttp-sub-kib-cpu-optimization.completed.md`。

本规格只在 `@uxu-code:spec` 阶段定义行为与验收标准；实现与本轮审查修复分别由后续公开工作流授权。

## 本次修订假设

- “这段文字”指当前场景的一行说明和其下四条共同限制，全部从主表单移入按需打开的说明模态框。
- “像 UUID 旁边的感叹号”指复用同款 `!` 按钮、遮罩模态框与关闭方式，不把连接说明塞进现有订阅鉴权/UUID 模态框。
- “下面的四个自定义选项”指预加载竞速开关、TCP 并发数、反代并发数和连接保活间隔四个现有控件。
- 旧配置无法匹配任何预设时，页面必须自动选择 `custom` 并显示四项控件，否则用户无法查看或修正已有值。

## 目标

让 CfGfwAX 管理员无需理解四项底层连接参数，也能根据主要诉求选择保守、可解释的预设，同时继续支持逐项自定义。

目标用户是使用管理页配置代理、但不希望自行试错拨号并发与保活间隔的管理员。

成功意味着：

- 用户能通过紧凑的场景下拉框选择预设，不再被常驻长说明和无关参数占用页面空间；
- 用户可通过“使用场景”旁的 `!` 按钮按需查看当前预设说明与共同限制；
- 用户选择“自定义”后能看到并逐项修改四项数值，已有数值不会被静默覆盖；
- UI 不把建连优化误称为视频吞吐或整体网速优化；
- 环境变量覆盖、传输协议适用范围和新连接生效边界均有清晰提示；
- 不改变 Worker 配置接口、现有默认值或运行逻辑。

## 已确认行为

| 设置 | 默认值 | 实际作用 | 不作用于 |
| --- | ---: | --- | --- |
| `PRELOAD_RACE_DIAL` | `false` | 首次直连 TCP 域名时并行 DoH 查询 A/AAAA，再按 TCP 并发上限竞速候选 IP | ProxyIP、显式上游代理、IP 目标、UDP |
| `TCP_CONCURRENT_DIAL` | `2` | 决定直连 TCP 同时尝试的连接数 | 已建立连接的吞吐、缓冲、分片和保活 |
| `PROXY_CONCURRENT_DIAL` | `1` | 决定 ProxyIP 地址池每批同时尝试的候选数 | 直连、显式上游代理、已建立连接吞吐 |
| `KEEPALIVE_INTERVAL` | `30000` | WebSocket 发送空文本帧、gRPC 发送空 protobuf 消息的周期 | XHTTP 定时保活、TCP 拨号、视频吞吐、UDP 目标 |

补充约束：

- 环境变量存在时优先于 KV `config.json`，所以管理页保存值可能被覆盖。
- 修改只影响新建连接；已建立的 WebSocket/gRPC 定时器必须重连后才使用新值。
- 视频若走 QUIC/UDP，前三项 TCP 设置不会参与目标连接。
- 竞速只可能改善首连、重连和失败切换，不直接提高持续吞吐。
- Cloudflare 当前限制每次调用最多六个仍在等待建立或响应头的出站连接；预设并发必须保守低于该上限。平台依据：[Workers Limits](https://developers.cloudflare.com/workers/platform/limits/)。

## 预设合同

| 稳定 ID | UI 名称 | 预加载竞速 | TCP 并发 | ProxyIP 并发 | 保活间隔 | 适用说明 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| `balanced` | 网页/视频（均衡） | 关 | 2 | 1 | `30000` ms | 与当前默认完全一致；常规浏览和视频使用 |
| `long_lived` | WS/gRPC 长连接 | 关 | 2 | 1 | `15000` ms | Codex 等存在较长空闲阶段的 WS/gRPC；XHTTP 不受保活值影响 |
| `weak_network` | 弱网快速建连 | 开 | 3 | 2 | `30000` ms | 域名直连或不稳定 ProxyIP 池；以额外 DoH/socket 换取首连或失败切换机会 |
| `resource_saver` | 节省连接资源 | 关 | 1 | 1 | `60000` ms | 连接资源优先；容忍更慢的失败切换与更稀疏的 WS/gRPC 活动 |
| `custom` | 自定义 | 保留 | 保留 | 保留 | 保留 | 高级用户逐项配置 |

不提供单独的“视频加速”预设。网页和视频归入均衡场景，并明确四项参数主要影响建连与 WS/gRPC 空闲活动，不控制媒体吞吐。

## 管理页交互

- “使用场景”继续使用带可见 `<label>` 的原生 `<select>`，五个选项、稳定 ID 和数值映射均不变。
- 用现有 `.label-with-hint` 包裹“使用场景”标签与 `!` 按钮；按钮复用 UUID 旁 `.inline-hint-btn` 的尺寸、颜色、焦点样式和点击模式，提供 `title` 与 `aria-label="查看使用场景说明"`。
- 删除下拉框下方常驻的预设说明段落和限制列表；点击 `!` 后打开独立的“使用场景说明”模态框，不把连接说明耦合到订阅鉴权/UUID 内容切换逻辑。
- 说明模态框复用现有模态框视觉与遮罩行为，不新增依赖或视觉主题；其中显示当前下拉选项的名称、对应说明及以下共同限制：
  - 环境变量存在时优先，可能覆盖此处保存值；
  - 设置只影响新建连接，现有长连接需重连；
  - 竞速主要影响建连与失败切换，不直接提高视频吞吐；
  - WS/gRPC 长连接预设的保活值不作用于 XHTTP。
- 说明模态框在每次打开时读取当前选择；切换下拉项后再次打开必须显示新场景说明。说明不能只存在于 `title`，屏幕阅读器也能通过按钮名称和模态框标题理解入口与内容。
- 将“预加载竞速拨号、TCP 并发拨号数、反代并发拨号数、连接保活间隔”包在一个自定义设置容器内：
  - 当前选择不是 `custom` 时，容器使用原生 `hidden` 语义隐藏，四项控件不可见且不可被 Tab 聚焦；
  - 当前选择是 `custom` 时，容器显示，四项控件的标签、最小值、校验和保存行为保持不变；
  - 隐藏只影响显示，不禁用、清空或移除控件，预设值仍按既有接口保存。
- 选择非 `custom` 项时，一次性把对应四个值写入现有控件、隐藏自定义设置容器，并将 `proxy` 模块标记为已修改。
- 选择 `custom` 时不得清空、重置或改写任何现有数值；只显示自定义设置容器，并保持下拉框为“自定义”。
- 用户修改自定义控件时保持 `custom` 选择和容器可见，即使四项值恰好匹配某个预设，也不在编辑过程中自动切回预设。
- 初次加载、刷新或取消修改时，根据已保存的四项值推断模式：精确匹配预设则选择该预设并隐藏容器，否则选择 `custom` 并显示容器。
- 自定义保存成功后，本次页面会话保持 `custom` 与容器可见；刷新后仍按已保存值重新推断。预设 ID 仍不持久化。
- 复用现有布局、颜色、间距和表单风格，不新增卡片、依赖或视觉主题。
- `!` 按钮、下拉框、模态框关闭控件和四项自定义控件均可用键盘操作；打开模态框后焦点进入模态框，`Tab` 与 `Shift+Tab` 不得逃逸到遮罩后的页面，`Escape`、关闭按钮或点击遮罩可关闭，关闭后焦点返回 `!` 按钮。
- 320、768、1024、1440 px 宽度下无横向溢出；预设模式不得为隐藏容器保留空白高度。

## 风险与控制

- **误导性性能承诺**：说明文字区分建连、保活和吞吐，不使用“视频加速”。
- **自定义值丢失**：选择 `custom` 不写值；任何未知组合稳定显示 `custom`。
- **隐藏字段丢失或未保存**：容器只做显示隐藏，不 `disabled`、不清空；选择预设仍先写入四项值再保存。
- **编辑中突然收起**：自定义输入事件不反推预设；只有用户选择预设或重新加载/取消时才离开当前自定义编辑状态。
- **说明入口不可发现或不可访问**：复用 UUID 的 `!` 视觉，并要求可读按钮名称、模态框标题、模态框内焦点约束、键盘关闭和焦点返回。
- **保存兼容性**：不持久化预设 ID，只保存现有四项字段。
- **环境变量覆盖**：管理页明确提示，不伪装为当前运行有效值。
- **布局回归**：复用 `.connection-settings` 范围样式并保留 checkbox 固定宽度回归。
- **预设数值未经普适生产证明**：把它们定义为保守起点，不表述为全局最优。

1. 第一阶段只改现有配置的表示层，四项保存值与接口完全兼容。
2. 下拉框包含已批准的五项及精确数值映射。
3. “使用场景”旁的 `!` 与 UUID 提示入口视觉一致；主表单不再常驻显示场景说明和四条限制。

6. 选择 `custom` 不改值，自定义编辑不自动切回预设；选择预设会写入精确映射并隐藏控件。
7. 加载、刷新和取消修改按保存值推断；自定义保存成功后的当前会话保持 `custom` 可见，刷新后重新推断。
8. 隐藏不改变四项字段的校验、保存值、接口形状或 Worker 运行行为。
9. 测试位于 `CGAX-Pages/work-products/tests/`，并从最终位置以相对路径引用产品文件。
10. 两仓库回归、语法检查和 `git diff --check` 通过。
11. 简体中文、繁体中文、英文说明语义同步。
12. 不实现自适应、自动应用识别、KV 自动改写或 Worker 运行逻辑变更。
13. 本地证据不表述为 Cloudflare、Codex 或视频播放的生产证明。

## 边界

### 始终执行

- 保留自定义值与显式 `custom` 编辑状态；
- 复用现有接口和 UI 风格；
- 让隐藏状态只影响呈现，不影响数据或保存；
- 在表单边界验证整数和最小值；
- 区分仓库验证与生产效果；
- 保持三语文档同步；
- 按仓库规则更新版本、版本断言和 `CHANGELOG`。

### 先询问

- 调整任何已批准的预设名称或数值；
- 给自定义并发增加最大值或改变现有最小值；
- 修改 Worker 运行逻辑或配置 API；
- 增加依赖或改变发布流程。

### 永不执行

- 制作自适应策略或应用域名识别；
- 把预设宣传为视频吞吐加速；
- 自动改写 KV；
- 记录目标域名、路径、凭据或原始数据；
- 将本地测试冒充生产验证；
- 执行 Wrangler 直接部署。
